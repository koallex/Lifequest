LIFE QUEST v1.0
1. Распакуйте архив.
2. Откройте index.html в браузере для локального тестирования.
3. Для установки как PWA разместите все файлы на HTTPS-хостинге (например, Vercel или GitHub Pages), затем выберите в браузере «Добавить на главный экран».
Данные сохраняются в localStorage браузера на этом устройстве. Для переноса/резервной копии используйте экспорт данных в настройках браузера или сохраните данные сайта.
В этой версии: задачи (CRUD), ежедневные/еженедельные/разовые циклы, отметки по датам, календарь, XP/уровни, монеты, достижения, магазин наград, диаграммы.
