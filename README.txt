LIFE QUEST — готовый пакет для публикации
==========================================

Что внутри
  index.html            само приложение (один файл)
  manifest.webmanifest  данные для установки на главный экран
  sw.js                 работа без интернета (service worker)
  favicon.svg, apple-touch-icon.png, icons/   значки приложения

Проверка на компьютере
  Откройте index.html двойным щелчком — приложение работает.
  Установка на главный экран и офлайн-режим требуют HTTPS (см. ниже).
  Для локального теста с этими функциями: в папке выполните
  "python3 -m http.server 8000" и откройте http://localhost:8000

Публикация (любой способ, все бесплатные)
  1) Netlify Drop: зайдите на app.netlify.com/drop и перетащите
     распакованную папку целиком. Адрес со значком замка (HTTPS) появится сразу.
  2) GitHub Pages: создайте репозиторий, загрузите все файлы в корень,
     в Settings → Pages выберите ветку main и папку / (root).
  3) Vercel или Cloudflare Pages: импортируйте репозиторий или загрузите папку,
     настройки сборки не нужны (Framework: Other, без build-команды).

Установка на телефон
  iPhone (Safari): «Поделиться» → «На экран Домой».
  Android (Chrome): меню ⋮ → «Установить приложение».
  Компьютер (Chrome/Edge): значок установки в адресной строке.

Важно знать
  • Данные хранятся в браузере устройства (localStorage) отдельно для каждого
    адреса сайта. Прогресс не переносится между телефоном и компьютером, а при
    смене адреса (домена) начинается заново. Очистка данных сайта удалит прогресс.
  • Шрифты подгружаются с Google Fonts. Без интернета при первом запуске будет
    запасной шрифт; после первого онлайн-запуска шрифты кэшируются.
  • Обновление: замените index.html и в sw.js увеличьте число в VERSION
    (например life-quest-v2), чтобы устройства взяли новую версию.
