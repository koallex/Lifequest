LIFE QUEST — готовый пакет для публикации
==========================================

Что внутри
  index.html            само приложение (один файл)
  manifest.webmanifest  данные для установки на главный экран
  sw.js                 работа без интернета (service worker)
  favicon.svg, apple-touch-icon.png, icons/   значки приложения

Проверка на компьютере
  Откройте index.html двойным щелчком — приложение работает.
  Установка на главный экран и офлайн-режим требуют HTTPS (см. ниже).
  Для локального теста с этими функциями: в папке выполните
  "python3 -m http.server 8000" и откройте http://localhost:8000

Публикация (любой способ, все бесплатные)
  1) Netlify Drop: зайдите на app.netlify.com/drop и перетащите
     распакованную папку целиком. Адрес со значком замка (HTTPS) появится сразу.
  2) GitHub Pages: создайте репозиторий, загрузите все файлы в корень,
     в Settings → Pages выберите ветку main и папку / (root).
  3) Vercel или Cloudflare Pages: импортируйте репозиторий или загрузите папку,
     настройки сборки не нужны (Framework: Other, без build-команды).

Установка на телефон
  iPhone (Safari): «Поделиться» → «На экран Домой».
  Android (Chrome): меню ⋮ → «Установить приложение».
  Компьютер (Chrome/Edge): значок установки в адресной строке.

Важно знать
  • Данные хранятся в браузере устройства (localStorage) отдельно для каждого
    адреса сайта. Прогресс не переносится между телефоном и компьютером, а при
    смене адреса (домена) начинается заново. Очистка данных сайта удалит прогресс.
  • Шрифты подгружаются с Google Fonts. Без интернета при первом запуске будет
    запасной шрифт; после первого онлайн-запуска шрифты кэшируются.
  • Обновление: замените index.html и в sw.js увеличьте число в VERSION
    (например life-quest-v2), чтобы устройства взяли новую версию.

Новое в этой версии
  • На главной странице появилась карточка «Мысль дня».
  • Встроена библиотека из 110 оригинальных мотивирующих формулировок.
  • Мысль сохраняется на весь день и не меняется при повторном открытии.
  • Кнопка «Другая мысль» позволяет выбрать альтернативу.
  • Приложение ведёт историю уже показанных мыслей и избегает повторов,
    пока не пройдёт вся библиотека. После этого цикл начинается заново.
  • Подпись карточки учитывает день недели и сезон; часть библиотеки
    тематически привязана к дням недели и временам года.
  • Существующие данные LIFE QUEST сохраняются в прежнем localStorage.


Новое в этой версии — библиотека заданий
  • В разделе «Задания» добавлена библиотека из 40 готовых привычек.
  • Категории: здоровье, спорт, развитие, финансы, отношения, порядок,
    цифровой баланс и отдых.
  • Есть поиск по названию и описанию, а также фильтр по категориям.
  • Задание добавляется в личный список одним нажатием; повторное
    добавление того же шаблона блокируется.
  • Для каждого шаблона заданы рекомендуемая периодичность и сложность.
  • После добавления задание можно редактировать как обычное.
  • Прогресс, история и ранее созданные задания сохраняются.


ОБНОВЛЕНИЕ LIFE QUEST — компактная главная страница
- Главный экран перестроен вокруг списка заданий на выбранный день.
- Добавлен наглядный круговой индикатор выполнения, счётчик заданий и XP за день.
- Цитата дня стала компактнее и не отвлекает от основного действия.
- Уровень персонажа и общий XP собраны в небольшую строку прогресса.
- Календарь и график перенесены в раскрываемый блок «Календарь и статистика».
- На мобильных устройствах навигация закреплена внизу экрана.
- Добавлены мягкие переходы; системная настройка уменьшения анимации учитывается.
- Данные, задания, навыки, библиотека, цитаты и достижения сохраняются в прежнем локальном хранилище.
